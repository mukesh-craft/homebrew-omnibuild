# homebrew-omnibuild

Homebrew tap for [OmniBuild](https://github.com/mukesh-craft/omnibuild).

```bash
brew tap mukesh-craft/omnibuild
brew install mukesh-craft/omnibuild/omnibuild
omnibuild --version
omnibuild doctor
```

`v0.1.1` currently provides a macOS ARM64 asset. The Intel `x86_64-apple-darwin` SHA is a placeholder until that release asset is published; do not claim Intel support until the hash and install check are verified.
